## 공통 레이아웃

### 데스크톱 레이아웃

```
+----------------------------------------------------------------------------------------+
|  HEADER                                                                                |
|  +------------------+  +----------------------------------------------------------+   |
|  | [로고] Todolist  |  |                                    [🔔 3]  [👤 김철수 v] |   |
|  +------------------+  +----------------------------------------------------------+   |
+--------+-------------------------------------------------------------------------------+
|        |                                                                               |
| SIDEBAR|  MAIN CONTENT AREA                                                            |
|        |                                                                               |
| [🏠]  대시보드                                                                         |
| [✓]  할일 목록                                                                         |
| [🏷]  카테고리                                                                         |
| [👥]  팀 관리                                                                          |
|  ──────                                                                                |
| [팀 A]                                                                                 |
| [팀 B]                                                                                 |
|  ──────                                                                                |
| [⚙]  내 정보                                                                           |
| [→]  로그아웃                                                                          |
|        |                                                                               |
+--------+-------------------------------------------------------------------------------+

* 사이드바 고정 너비: 200px
* 헤더 고정 높이: 56px
* 알림 벨 아이콘에 미읽은 수 빨간 뱃지 표시
* 사용자 이름 클릭 시 드롭다운: [내 정보], [로그아웃]
```

## WF-01. 로그인 / 회원가입

### WF-01-A. 로그인

```
+----------------------------------------------------------------------------------------+
|                                                                                        |
|                          +-----------------------------------+                         |
|                          |        Todolist-App               |                         |
|                          |   효율적인 할일 관리 서비스         |                         |
|                          +-----------------------------------+                         |
|                                                                                        |
|                          +-----------------------------------+                         |
|                          |  로그인                           |                         |
|                          |                                   |                         |
|                          |  이메일                           |                         |
|                          |  [_____________________________]  |                         |
|                          |                                   |                         |
|                          |  비밀번호                         |                         |
|                          |  [_____________________________]  |                         |
|                          |                                   |                         |
|                          |  [ ] 로그인 상태 유지              |                         |
|                          |                                   |                         |
|                          |  [        로그인        ]         |                         |
|                          |                                   |                         |
|                          |  비밀번호를 잊으셨나요?            |                         |
|                          |  [비밀번호 찾기]                   |                         |
|                          |                                   |                         |
|                          |  ────────────────────────────     |                         |
|                          |                                   |                         |
|                          |  아직 계정이 없으신가요?           |                         |
|                          |  [       회원가입하기      ]       |                         |
|                          +-----------------------------------+                         |
|                                                                                        |
+----------------------------------------------------------------------------------------+

* 이메일/비밀번호 유효성 오류 시 필드 하단에 빨간색 오류 메시지 표시
* "로그인" 버튼: 주색상(Primary Blue) 채움 버튼
* "회원가입하기": 아웃라인 버튼 또는 텍스트 링크
* "비밀번호 찾기": 텍스트 링크 스타일
```

### WF-01-B. 회원가입

```
+----------------------------------------------------------------------------------------+
|                                                                                        |
|                          +-----------------------------------+                         |
|                          |  회원가입                         |                         |
|                          |                                   |                         |
|                          |  이메일                           |                         |
|                          |  +-------------------------+[확인] |                        |
|                          |  | example@email.com       |      |                         |
|                          |  +-------------------------+      |                         |
|                          |  ✓ 사용 가능한 이메일입니다.       |  <- 중복확인 후 표시    |
|                          |                                   |                         |
|                          |  비밀번호                         |                         |
|                          |  [_____________________________]  |                         |
|                          |  영문, 숫자, 특수문자 8자 이상     |                         |
|                          |                                   |                         |
|                          |  비밀번호 확인                    |                         |
|                          |  [_____________________________]  |                         |
|                          |  ✓ 비밀번호가 일치합니다.          |  <- 일치 시 표시        |
|                          |                                   |                         |
|                          |  이름 (선택)                      |                         |
|                          |  [_____________________________]  |                         |
|                          |                                   |                         |
|                          |  [       회원가입 완료      ]      |                         |
|                          |                                   |                         |
|                          |  이미 계정이 있으신가요?           |                         |
|                          |  [로그인]                         |                         |
|                          +-----------------------------------+                         |
|                                                                                        |
+----------------------------------------------------------------------------------------+

* 이메일 "확인" 버튼: Secondary 스타일, 클릭 시 중복 여부 API 호출
* 중복 시: ✗ 이미 사용 중인 이메일입니다. (빨간색)
* 비밀번호 불일치 시: ✗ 비밀번호가 일치하지 않습니다. (빨간색)
* 모든 필수 항목 충족 전까지 "회원가입 완료" 버튼 비활성화
```

## WF-02. 대시보드

### WF-02-A. 대시보드 (데스크톱)

```
+--------+-------------------------------------------------------------------------------+
| 사이드바|  대시보드                                                    [+ 할일 추가]    |
|        |                                                                               |
| [●] 대시보드  안녕하세요, 김철수님! 오늘도 활차게 시작해볼까요? 🌟              |
| [ ] 할일  2026년 5월 13일 (수요일)                                                    |
| [ ] 카테고리|                                                                          |
| [ ] 팀  +------------------+  +------------------+  +------------------+             |
|        |  전체 할일        |  |  완료              |  |  진행 중          |             |
|        |  📋 24개          |  |  ✓ 8개            |  |  ▶ 12개          |             |
|        +------------------+  +------------------+  +------------------+             |
|        |                                                                               |
|        |  ── 오늘 할일 ────────────────────────────────────────────  [전체 보기 >]    |
|        |                                                                               |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] 주간 팀 회의 준비              [진행중]    오늘 18:00  [업무] |          |
|        |  +----------------------------------------------------------------+          |
|        |  +----------------------------------------------------------------+          |
|        |  | [✓] 디자인 시안 검토                [완료]     오늘 12:00  [디자인]|         |
|        |  +----------------------------------------------------------------+          |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] API 명세서 작성               [예정]      오늘 23:59  [개발] |          |
|        |  +----------------------------------------------------------------+          |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] 운동하기                      [예정]      오늘 21:00  [개인] |          |
|        |  +----------------------------------------------------------------+          |
|        |                                                                               |
|        |  ── 이번 주 할일 ──────────────────────────────────────────  [전체 보기 >]   |
|        |                                                                               |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] 프로젝트 킥오프 미팅          [예정]    5/15 (금) 14:00  [업무]|        |
|        |  +----------------------------------------------------------------+          |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] 월간 보고서 제출              [진행중]  5/16 (토) 23:59  [업무]|        |
|        |  +----------------------------------------------------------------+          |
|        |  +----------------------------------------------------------------+          |
|        |  | [ ] 독서 - Clean Architecture    [예정]    5/14 (목)       [개인]|         |
|        |  +----------------------------------------------------------------+          |
|        |                                                                               |
+--------+-------------------------------------------------------------------------------+

* 상단 통계 카드 3개 가로 배치
* 할일 카드: 체크박스, 제목, 상태 배지, 마감일, 카테고리 태그
* [완료] 항목: 제목에 취소선 + 흐린 텍스트
* "전체 보기 >" 링크 클릭 시 해당 필터 적용된 할일 목록으로 이동
* "[+ 할일 추가]" FAB 우측 상단 배치
```

### WF-03-A. 할일 목록 (데스크톱)

```
+--------+-------------------------------------------------------------------------------+
| 사이드바|  할일 목록                                                   [+ 할일 추가]   |
|        |                                                                               |
| [ ] 대시보드  검색                                                                    |
| [●] 할일  [🔍 할일을 검색하세요...                              ]                    |
| [ ] 카테고리|                                                                          |
| [ ] 팀  +-------------------------------------------------------------------+         |
|        | 진행 상태 [v]  카테고리 [v]  마감일 [____] ~ [____]  [필터 초기화] |         |
|        +-------------------------------------------------------------------+         |
|        |                                                                               |
|        |  정렬: [마감일순 v]                        총 24개 (완료 8 / 진행 중 12 / 예정 4)|
|        |                                                                               |
|        |  +-------------------------------------------------------------------+       |
|        |  | [ ] 주간 팀 회의 준비                                              |       |
|        |  |     [진행중] [업무] [팀A]          마감: 2026-05-13 18:00         |       |
|        |  +-------------------------------------------------------------------+       |
|        |  +-------------------------------------------------------------------+       |
|        |  | [✓] 디자인 시안 검토                                              |       |
|        |  |     [완료]   [디자인]              마감: 2026-05-13 12:00        |       |
|        |  +-------------------------------------------------------------------+       |
|        |  +-------------------------------------------------------------------+       |
|        |  | [ ] API 명세서 작성                                               |       |
|        |  |     [예정]   [개발]                마감: 2026-05-13 23:59        |       |
|        |  +-------------------------------------------------------------------+       |
|        |  +-------------------------------------------------------------------+       |
|        |  | [ ] 프로젝트 킥오프 미팅                                          |       |
|        |  |     [예정]   [업무]  [팀B]         마감: 2026-05-15 14:00        |       |
|        |  +-------------------------------------------------------------------+       |
|        |  +-------------------------------------------------------------------+       |
|        |  | [ ] 운동하기                                                      |       |
|        |  |     [예정]   [개인]                마감: 2026-05-13 21:00        |       |
|        |  +-------------------------------------------------------------------+       |
|        |                                                                               |
|        |  -- 빈 상태 (할일 없음) --                                                   |
|        |  +-------------------------------------------------------------------+       |
|        |  |                                                                   |       |
|        |  |              📋                                                   |       |
|        |  |         할일이 없습니다.                                          |       |
|        |  |     [+ 첫 번째 할일 추가하기]                                     |       |
|        |  |                                                                   |       |
|        |  +-------------------------------------------------------------------+       |
|        |                                                                               |
+--------+-------------------------------------------------------------------------------+

* 각 할일 행 클릭 시 상세/편집 페이지로 이동
* [완료] 항목: 제목 취소선 표시, 행 배경 흐리게
* [진행중]: 파란색 배지, [완료]: 초록색, [예정]: 회색, [보류]: 노란색
* 카테고리 태그: 각 카테고리 지정 색상으로 표시
* 팀 태그: 팀 이름 표시 (팀 할일인 경우)
* 필터 적용 시 "필터 초기화" 버튼 활성화 (기본: 비활성)
```

```
  - TODO_ASSIGNED → 📋 (클립보드)
* TEAM_INVITE: 수락/거절 버튼 인라인 표시 (대기 중인 경우만)
* 수락/거절 후: 버튼 숨기고 "(수락됨)" 또는 "(거절됨)" 텍스트 표시
* 알림 클릭 시 해당 관련 페이지로 이동
```
